{%- seo -%} {%- feed_meta -%} {%- if jekyll.environment == 'production' and site.google_analytics -%} {%- include google-analytics.html -%} {%- endif -%} {%- comment -%} The site's head include, derived from Minima's, which loads the live-reload client itself. Jekyll adds its own live-reload script after a lower-case tag, and that script names port 35729 of the page's host, which Dockside's proxy does not publish. So the tag is written in upper case (HTML does not mind), which Jekyll does not match. Behind Dockside's proxy the page is served at www-. and the live-reload server is the profile's `ws` router, at ws-. on the proxy's port. Anywhere else, the client is loaded from port 35729 of the page's host, as Jekyll would. {%- endcomment -%}
